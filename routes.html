路线导览

“连点成线、串珠成链”，构建沉浸式胡同文化体验

“京味烟火之旅”是一条融合老北京美食文化与胡同历史记忆的步行路线。从铜锅涮肉与朝鲜冷面的舌尖对决开始，到一壶清茶、几碟点心的悠然午后，再到老字号糕点铺的京味传承；从元大都遗存的胡同肌理，到藏书楼、电影摇篮、抗日名将路、梨园故居的层层递进——这条不足两公里的路线，浓缩了西四北街区七百余年的市井生活与人文底蕴。

欢迎您亲自走一趟，感受这座古都最真实的烟火气。

二、京味烟火之旅

【游览路线】：古铜老院铜锅涮肉·清真 / 华天延吉餐厅 → 易应茶舍 → 紫光园 / 德盛斋老北京清真糕点 → 西四北五条 → 赵登禹路 → 西四北三条

【游览建议】：建议在古铜老院或华天延吉餐厅享用午餐，下午于易应茶舍品茶休憩，随后前往紫光园与德盛斋选购老北京糕点或伴手礼。之后依次穿行西四北五条、赵登禹路、西四北三条。全程步行约2–3小时。沿线多处故居不对外开放，请外观游览并尊重居民生活。

1. 古铜老院铜锅涮肉·清真/华天延吉餐厅

线路起点位于西四北大街东侧北段。从地铁4号线西四站A口出站，步行约200米即可到达两家紧邻的老字号餐厅，可依据个人口味选择午餐。

古铜老院铜锅涮肉·清真
经营传统炭火铜锅涮肉，清汤锅底赠送羊尾油以润锅提香。羊肉产自内蒙古呼伦贝尔草原，手切羊肉鲜嫩无膻味。招牌菜包括高钙羊肉（带脆骨）、半边云（肥瘦相间）及老院三宝。蘸料为现磨芝麻酱，主食推荐老院糖饼（红糖流心）和糖火烧。

华天延吉餐厅
始创于1943年的朝鲜冷面老字号。现压荞麦冷面口感劲道爽滑，牛肉汤底经冰镇后酸甜清凉。推荐配菜为拌桔梗及以牛肉制作的锅包肉（外酥里嫩，糖醋蒜香风味）。

2. 易应茶舍

饱餐之后，可前往易应茶舍享用下午茶。该茶舍位于延吉餐厅以北不远处，是一处闹中取静的中式茶空间。茶品以张一元茉莉花茶、普洱、老白茶为主，茶点包括老北京自来红、自来白、茯苓饼等。午餐时段还提供温润的茶泡饭套餐。一壶清茶，几碟红炉点心，在此感受西四的慢时光。

3. 紫光园 / 德盛斋老北京清真糕点

继续向北，可到达两家老北京特产店铺。在此选购伴手礼或边逛边品尝点心，体验老北京市井饮食文化与糕点传承。

紫光园：
老北京酸奶：奶香浓郁，口感醇厚，微带酸香，为胡同游客常选饮品。
驴打滚 / 艾窝窝：传统京味小吃，外皮软糯，内馅绵密，保留经典风味。
糖火烧：外皮酥脆，内馅香甜，层次分明。

德盛斋老北京清真糕点：
糖耳朵：外皮金黄酥脆，内馅绵密香甜，形似耳朵。
蜜三刀：外裹糖汁，内馅软糯，甜而不腻。
绿豆糕：口感细腻，豆香浓郁，入口即化。
鲜花玫瑰饼：外皮酥松，内馅带有玫瑰清香。

4. 西四北五条

从德盛斋旁的路口向西拐入，即到达西四北五条胡同。该胡同东起西四北大街，西至赵登禹路，全长498米。为元大都棋盘式街巷遗存，元代属鸣玉坊，明清属正红旗。

核心看点：
傅增湘故居：1918年，近代藏书家、曾任教育总长的傅增湘在此购地建宅，取苏东坡“万人如海一身藏”诗意，命名为藏园，园内藏书楼名为双鉴楼。鼎盛时期藏书达20余万卷，为民国北方私家藏书之冠。同一院落也曾住过奉系军阀张宗昌（“三不知将军”）。
北京电影学院前身：1950年，中央文化部电影局在4号院创办表演艺术研究所，即北京电影学院的发源地，新中国电影教育由此起步。
一条胡同汇聚了接生婆的市井温情、藏书家的书香、军阀的混世传说与电影教育的摇篮。

5. 赵登禹路

走出西四北五条西口，即踏上南北向的赵登禹路。该路北起西直门内大街，南至阜成门内大街，全长约1.9公里，前身为元代金水河故道、明清时期的西沟沿。1946年，为纪念抗日殉国的赵登禹将军而命名，与佟麟阁路、张自忠路并列为北京仅有的三条以现代人名命名的道路。

6. 西四北三条

从赵登禹路向东拐入，即达线路终点——西四北三条。该胡同东起西四北大街，西至赵登禹路，全长527米。明代称“箔子胡同”，清代演变为“雹子胡同”“报子胡同”，1965年改今名。

核心看点：
程砚秋故居（39号院）：京剧“四大名旦”之一程砚秋于1937年至1958年在此居住。书房名御霜簃。日伪时期，他拒绝为日本人演出，隐居务农，展现铮铮傲骨。故居现为北京市文物保护单位。
马福祥故居（11号院）：清末民初武举、蒙藏委员会委员长马福祥宅邸。西侧为宅院，东侧为花园。花园内叠石为山，上有爬山游廊、绣楼和八角亭，部分院落现已改为幼儿园。
这条胡同汇集了古寺梵音、梨园风骨与将军府邸遗存，是西四北历史街区最精华的段落之一。

7. 结语

“京味烟火之旅”是一条融合老北京美食文化与胡同历史记忆的步行路线。从铜锅涮肉与朝鲜冷面的舌尖对决开始，到一壶清茶、几碟点心的悠然午后，再到老字号糕点铺的京味传承；从元大都遗存的胡同肌理，到藏书楼、电影摇篮、抗日名将路、梨园故居的层层递进——这条不足两公里的路线，浓缩了西四北街区七百余年的市井生活与人文底蕴。

欢迎您亲自走一趟，感受这座古都最真实的烟火气。

“人文寻踪线”是一条深度寻访胡同古迹的路线。建议从西四北大街的护国双关帝庙启程，一路寻访胡同深处的古寺、名人宅邸与形形色色的老北京传统宅门。从元代的信仰遗存，到明清的建筑规制，再到近现代的文人风骨——这条路线将为您揭开胡同“门第”等级的奥秘，带您走进一段厚重的历史文化之旅。

欢迎您亲自走一趟，开启这段跨越时空的人文寻踪。

一、人文寻踪线

【游览路线】：护国双关帝庙 → 西四北三条（圣祚隆长寺 / 门楼 / 马福祥故居 / 程砚秋故居） → 赵登禹路 → 西四北四条 → 西四北大街 → 西四北五条（中央电影局表演艺术研究院旧址 / 傅增湘故居）

【游览建议】：建议从西四北大街的护国双关帝庙启程，一路寻访胡同深处的古寺、名人宅邸与形形色色的老北京传统宅门。全程步行约1小时。沿线多处故居、学校旧址及私人宅院（如傅增湘故居、京师附小等）不对外开放，请以外观游览为主，尊重当地居民生活。

1. 护国双关帝庙（西四北大街）

线路起点位于西四北大街。在步入胡同之前，首先映入眼帘的是护国双关帝庙。作为老北京的信仰遗存，这处庄严的古建为您开启这段厚重的历史文化之旅定下了古朴的基调。参观完毕后，从关帝庙向北不远，向西拐入便正式踏入胡同的肌理。

2. 西四北三条（古寺、百态宅门与名流故居）

西四北三条是一条名副其实的“古建博物馆”胡同。这里不仅有古寺梵音，更是实地观察老北京四合院各种“门第”等级的绝佳去处。

核心看点：
圣祚隆长寺：位于胡同东口，承载着明清时期的宗教文化记忆，为胡同增添了宁静与肃穆的气息。
传统宅门大赏：漫步胡同，您可以一次性集齐老北京四合院的多种宅门形制。从代表权贵的广亮大门、金柱大门，到富商阶层偏爱的蛮子门、如意门，再到中西合璧的西洋门以及寻常百姓家的随墙门。这些形态各异的门头，生动诉说着昔日主人的身份与地位。
马福祥故居：清末民初将领马福祥的宅邸。宏大的院落格局与精美的宅门，展现了民国时期将军府邸的建筑风貌与昔日威仪。
程砚秋故居：靠近胡同西侧，是京剧“四大名旦”之一程砚秋先生的故居。宅邸内的书房“御霜簃”见证了他日伪时期拒绝为日本人演出、隐居务农的铮铮铁骨，展现了不屈的民族气节。

3. 赵登禹路与西四北四条（百年学府的印记）

穿出西四北三条西口，短暂沿南北走向的赵登禹路向北行进，随后向东拐入西四北四条。

核心看点：
西四北四条是元大都坊巷的活化石，以百年教育文脉为核心。这里有从清代八旗官学延续至今的京师附小，承载齐白石、纪堪颐办学往事与众多文化名人足迹；没有刻意打造的景区、没有售票景点、没有网红打卡装置，是一条完完整整、原汁原味的老北京原生胡同。这里保留着元大都以来的坊巷肌理，青灰砖墙、木门小院、老树遮荫，居民日常出入、邻里闲谈、晾晒衣物、推车慢行，一切都是最自然、最松弛、最真实的老城日常。

4. 西四北五条（电影摇篮与藏书大家）

走过西四北四条后，再次回到西四北大街向北行进，最后折返向西进入西四北五条。这条胡同承载了厚重的民国学术与新中国艺术发展史。

核心看点：
中央电影局表演艺术研究院旧址：漫步其间，会途经新中国电影教育的发源地。1950年，这里孕育了无数早期电影艺术人才，是北京电影学院的前身，见证了中国电影事业的起步。
傅增湘故居：近代著名藏书家、曾任教育总长的傅增湘宅邸“藏园”。园内曾建有著名的藏书楼“双鉴楼”，鼎盛时期为民国北方私家藏书之冠，为这段旅程画上添上一抹书香气韵。

5. 结语：

这趟“西四古建门第与人文寻踪之旅”，是一场穿越明清与民国的建筑与人文对话。从胡同口庄严的关帝庙与古寺，到三条里诉说着阶层秩序的百态宅门；从四大名旦的梨园风骨与将军府邸的岁月痕迹，再到四条的百年学府与五条的电影摇篮、藏书名楼——这条曲折迂回的路线，如同一部立体的北京胡同百科全书。

欢迎您亲自走一趟，在青砖灰瓦间触摸这座古都的文化脉络与门第浮沉。

“清享漫游线”是一条专为年轻人设计的“日咖夜酒”慢时光路线。从闹中取静的精品咖啡开启午后，漫步西四北原生胡同，最后以精酿小酌收尾。

在这里，适合与闺蜜一起，定格胡同里最轻盈的时光。

三、日咖夜酒·清享漫游线

【游览路线】：无问西东·咖啡—胡同漫步（西四北三条、四条）—Puffin Coffee 海鹦咖啡—大宇宙 Great Cosmos—蝗虫精酿

【游览建议】：建议午后从无问西东・咖啡开启胡同慢时光，享受露台与猫咪陪伴的惬意下午茶；随后步行至海鹦咖啡浅尝西四口碑榜首咖啡；沿途漫步西四北三条、四条、五条原生胡同，感受真实老北京生活；傍晚进入大宇宙体验日咖夜酒的松弛氛围，入夜后到蝗虫精酿小酌收尾。全程步行约 2.5–3.5 小时，路线轻松舒适，不赶场、不硬饮，适合年轻人、闺蜜出行与拍照打卡。避免同质化体验。

1. 无问西东·咖啡

线路起点位于西四北大街南部，闹中取静的胡同精品咖啡店。店内氛围温暖柔和，拥有露台景观位与可爱猫咪，是胡同旁极具人气的休憩空间。

推荐特色：
狮狮如意：冰奶＋咖啡做的小狮子，小狮子在冰奶中慢慢融化，再淋上杏仁酒，酒香与奶香融合，口感微润又有层次~
老北京卡布奇诺：搭配老北京特色小吃—驴打滚，加上青花瓷的杯子，喝到杯底还有麻酱，妥妥的老北京气息~
还有好事发生、咸奶油冰美式、咸蜂蜜拿铁等特调咖啡等你品尝
午后阳光洒入院落，一杯咖啡、一段慢时光，最适合开启轻松的胡同漫游。

2. 胡同漫步（西四北三条—西四北四条—西四北五条）

品鉴完咖啡，向北步行一段距离，就可以拐进胡同深处。这里没有景点式的喧闹，只有老北京最日常的呼吸声。

三条·梨园旧梦
进入三条胡同，脚步不自觉放轻。11号院的马福祥故居藏着叠石游廊和八角亭，现在改成了幼儿园，童声代替了当年的觥筹交错。39号院是程砚秋住了二十一年的故居，灰墙青瓦，门扉轻掩。想象当年水袖起落、唱腔绕梁，如今只剩树影斑驳。

四条·寻常人家
四条更安静，是真正的“生活着的胡同”。晾衣绳上的被单、窗台上的花盆、拄着拐杖晒太阳的老人……时间在这里变得很慢。不必刻意寻找什么景点，随便走走，抬头看看老槐树和鸽子笼，就是最地道的京味。

五条·文脉深处
五条的故事最耐人寻味。傅增湘的“藏园”曾藏书二十万卷，张宗昌这个“三不知将军”也在这里住过。最传奇的是4号院。1950年，北京电影学院的前身就在这个不起眼的小院里诞生。从接生婆的“石老娘”到电影摇篮，一条胡同串起了七百年的烟火与文脉。

一次胡同漫步，让人真正走进这座城市的肌理。没有攻略，没有终点，就顺着青砖灰瓦的脉络，走哪儿算哪儿。阳光透过槐树叶洒下来，风里飘着邻家炒菜的香气——这才是北京最动人的时刻。

3. Puffin Coffee 海鹦咖啡

从五条胡同出来后，向北行进几十米，即可到达西四口味排名第一的咖啡店歇歇脚。门头简约有质感，还有临街窗户位，看看路边的大树和行人，度过一个轻松自在的午后时光。

推荐特色：
特调咖啡：秋天起，举个栗子，这次一定橙，当海风吹走落叶，苹苹无奇，冬瓜拿铁等
如果你对咖啡感兴趣，也可以和店里的小哥聊聊，听听他分享的所见所闻，感受他对咖啡的喜爱。

4. 大宇宙 Great Cosmos

傍晚氛围最佳，是从白天过渡到夜晚的完美节点。灯光柔和、环境松弛，不吵不闹，适合坐下聊天、放松心情，一碗小吃，一杯精酿，衔接夜晚微醺。

推荐特色
小吃：炸灌肠，羊腿肉串配酸黄瓜，黑胡椒鱿鱼鸡胗
饮品：客啤与自酿融合兼具果香层次：击倒巨人震荡暴龙苏三；惠比寿琥珀拉格（清爽解暑）

5. 蝗虫精酿

路线终点为蝗虫精酿小馆，氛围轻松自在，适合朋友小聚、轻酌慢饮。作为一天旅程的收尾，在微醺中回味胡同漫步的惬意，为日咖夜酒之旅画上圆满句号。

推荐特色：
彼岸酿造“德累斯顿的晚风”（未过滤拉格，香气足、杀口利落）
